# Security

This program is injected into OpenXR games as an API layer and writes only to
`%APPDATA%\VirtualPrismOpenXR` and (for the layer install) `HKCU\SOFTWARE\Khronos\OpenXR\1\ApiLayers\Implicit`.

If you find a security problem, please do **not** open a public issue. Use
**Security > Report a vulnerability** on this repository (private vulnerability reporting).

Only download releases from this repository's Releases page.
